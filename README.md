# ai-readiness-assessment

Part of the [GENIA Americas AI Toolkit](https://github.com/GENIA-Americas) — repo #1, the
entry point. Backend-only API (no frontend) for scoring an organization's readiness to adopt AI.

## Stack

Versions below were verified by actually installing them, not assumed from memory:

- fastapi 0.139.2
- pydantic 2.13.4
- SQLAlchemy 2.0.51
- uvicorn 0.51.0
- pytest 9.1.1 / httpx 0.28.1 (dev/test only)

These will drift over time. Run `pip list --outdated` yourself before pinning newer versions.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate   # on Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

## Run

```bash
uvicorn app.main:app --reload
```

Interactive API docs (auto-generated by FastAPI): http://127.0.0.1:8000/docs

## Test

```bash
pytest tests/ -v
```

All 7 tests pass as of the last verified run in this repo's history.

## API

- `POST /assessments` — submit a questionnaire, get back scored categories, overall score
  (0-100), and a readiness tier (`Not Yet Ready` / `Foundational` / `Emerging` / `AI-Ready`).
- `GET /assessments/{id}` — retrieve one assessment.
- `GET /assessments` — list all assessments, most recent first.
- `GET /health` — liveness check.

## Scoring rubric

Five weighted categories, each averaged from two 0-5 questions, weights sum to 1.0:

| Category | Weight |
|---|---|
| Data readiness | 0.25 |
| Talent | 0.20 |
| Governance | 0.20 |
| Infrastructure | 0.20 |
| Leadership | 0.15 |

See `app/scoring.py` for the exact calculation and tier thresholds.
